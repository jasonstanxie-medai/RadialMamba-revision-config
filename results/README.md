# Recorded evaluation artifacts

See [results and interpretation](../docs/results.md) for metric definitions and the primary/secondary distinction. Summary CSVs and corrected recorded JSONs come from the completed evaluation. No scores were altered during repository preparation.

`per_study_results.csv` includes TP/FP/FN counts for verifying Dice and observed paired differences. It does not contain original images or pixel-level probabilities. The probability figures use continuous score maps, not argmax masks.
