# Reproducibility records

- `checkpoints.json`: SHA256 identities of selected primary and secondary weights. Weights are not bundled.
- `selection_record.json`: the development-stage checkpoint-selection record frozen before this holdout evaluation.
- `export_notes.md`: changes made when preparing this public layout.
- `files_sha256.json`: file identities of this export.

The split file and validation-study fingerprints appear in the [data guide](../docs/data.md). The [environment guide](../docs/environment.md) records the observed environment and remaining source-export requirements.
